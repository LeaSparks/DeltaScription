# The ground itself cracks as a fountain of darkness spews night from the earth...

Slay them? Spare them?, that's up to you to decide.



This mod adds cards for Act 1 Kaycee's Mod in the game Inscryption, inspired by the Darkners and Lightners from Toby Fox's Hit game deltarune.



PLEASE reach out to me on the Modding Discord if you encounter any bugs, visual or otherwise, this is an early access mod.



# Installation

If you're installing the mod manually:

- click the **Manual Download** button to download the package.

- Unzip the contents of the package to a new folder in your **plugins** directory.

- Make sure that you have installed all the dependencies required by this mod as well.

If you're using a mod manager it should just work.
